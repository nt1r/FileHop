# Triage Labels

Use this mapping when an engineering skill refers to a triage role.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting maintainer evaluation |
| needs-info | needs-info | Awaiting additional information |
| ready-for-agent | ready-for-agent | Fully specified and suitable for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be implemented |

Before applying labels, check the repository's existing labels.
This file records vocabulary; it does not mean the labels already exist
on GitHub. Create missing labels only within an authorized task.

`ready-for-agent` describes readiness, not permission to merge, deploy,
or modify production.

Edit the GitHub label column if the repository adopts different names.
