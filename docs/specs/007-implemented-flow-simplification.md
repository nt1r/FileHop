## 1. 已确认取舍

| 决定 | 用户承担的代价 | 实际删除目标 |
| --- | --- | --- |
| 只在服务器文件页删除，手动刷新结果 | 多一次切页/刷新，消息里的旧下载状态可暂时滞后 | 消息删除入口、删除进度轮询、跨页面删除操作上下文 |
| 保留本地“中断传输”，不保证服务器停止 | 中断时文件仍可能保存成功 | 服务端 stop、停止先于准备的持久标记及相关协调 |
| 每次文件发送仅一轮传输，明确失败后重新选择 | 重传属于新发送，不再一键同次重试 | 后继尝试协议、前驱链、文件重试操作 |
| 多选串行，未知结果默认暂停，可明确“结束本轮” | 批量可能更慢；结束后重选可能重复 | 三名额调度、单项放弃后隐式协调、未知结果自动恢复流程 |
| 登录失效本地中断、清空等待项，不自动恢复批次 | 重登后重新选择等待文件 | File 引用跨登录保留、自动查询并接续等待项 |

结束本轮须提示先检查历史；只结束客户端上下文，不证明旧服务器任务已结束。页面串行不承诺实例全局只有一个上传，后端并发额度及资源上限仍须有效。

## 2. 三个实施切片

### A. 删除流程先减负

- 修改 `web/src/deletion.ts`、`ServerFiles.tsx`、`Messages.tsx`、`Session.tsx`：删除操作归文件页所有，不再由会话持有跨页删除上下文。
- 移除自动删除进度调度和消息删除入口；文件页保留确认、一次请求反馈、手动刷新。
- 保留后端删除、活动读取保护、状态版本、清理恢复和真实容量查询。
- 用单入口正常删除及响应丢失后的手动刷新替换旧双入口/轮询用例；不重复整个存储故障矩阵。

### B. 单轮文件发送与串行上传一起收缩

- 修改 `backend/src/files.rs` 与路由、`web/src/files.ts` 和上传展示，撤销后继尝试及服务端停止职责。不能只藏按钮而保留一套无调用的协议。
- 保留准备、内容上传、结果查询和下载的现有形态；可保留单个 attempt_id 作为传输凭据，不为去掉一个字段额外重设计全部路由。
- 新发送只允许一轮文件体传输；准备请求重复不得多占额度，已终结发送不得重启。保留发送身份和成功记录。
- 页面只调度一个活动文件；未知结果由用户查询或结束本轮，不自动重新发送。中断仅停止本地请求，已成功不得改写为失败。
- 旧 stop/后继入口退役，不静默转换为新发送；更新前结束传输并刷新客户端，不建设兼容层。
- 实际表删除可后置：不得修改已应用 SQL、清库或删除已有消息/文件。用新增迁移或保留旧表的过渡方式保存既有成功身份和容量；旧未完成记录由启动恢复安全终结，旧控制记录不能因精简重新激活任务。

### C. 登录到期只保留必要信息

- 本地中断活动上传，清空等待队列和全部 File 引用；不改变服务器对已认证请求的自然到期规则。
- 保留文字草稿及未确认发送的最小身份/展示信息，未登录时隐藏；重新登录只恢复查询能力，不自动查询、重传或恢复批次。
- 已经结束本轮或主动退出的上下文不恢复；旧回调不能操作新一轮队列或重新展示隐私内容。
- 文本同次重试和文本放弃确认保持原行为。Android 以后实现时直接遵循新文件协议，不复建旧恢复体系。

A 可单独交付；B/C 相邻实施，避免重复重写上传状态。不新增通用调度器、插件、兼容层或测试平台；减少需要调用者理解的状态，优先真正删代码而不是搬文件。

## 3. 最小交付检查

| 编号 | 检查 |
| --- | --- |
| R01 | 仅文件页删除；无自动删除轮询，手动刷新后状态与用量正确；未确认不报完成 |
| R02 | 多选串行，文本独立；中断不谎报撤回，成功仍能通过原身份查询 |
| R03 | 未知默认暂停且无自动写请求；结束本轮后不再协调旧任务，重选为新身份且有重复风险提示 |
| R04 | 明确失败只能重新选择；无后继重传/服务端 stop；重复准备、重复内容请求不产生并行写入或重复消息 |
| R05 | 到期中断、等待项丢弃有提示；草稿与未确认身份可在重登后使用，文件队列不自动恢复；旧回调隔离 |
| R06 | 保留原账户、历史、成功身份和可下载文件；旧残留安全清理，容量不提前释放；原鉴权、存储/迁移保护不回退 |

沿用 HTTP + 隔离 SQLite/文件目录及少量真实后端浏览器流程。撤销承诺的专项测试随实现删除或改写，不为保留旧测试继续维护旧功能。保留仍适用的鉴权、额度、持久化和迟到响应回归；检查按改动风险执行，不人为凑全场景覆盖。

没有精确删行数目标，不把文件变短当完成；实际成果应能指出已移除的功能、状态与调用链。原 Spec 002/003 的历史验收仅证明旧版，新流程不能复用为已通过。本计划不授权部署、清理持久数据或自动更新远端 Issues/PR。
