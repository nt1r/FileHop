关联：[产品基线](../product.md) · [Spec 002](002-desktop-file-transfer.md) · [Spec 003](003-server-file-management.md) · [Spec 005](005-android-text-loop.md)。本文件是本切片唯一权威来源。

## 1. 目标与非目标

手机与 Web 双向上传、下载文件。上传使用系统文件选择器，下载保存到用户通过系统选择的位置，之后交给系统文件管理器打开、删除。

不建设独立本地下载页、本地副本索引数据库、应用内副本删除、持久下载任务及其崩溃恢复协议。不做后台可靠传输、断点续传、目录上传、系统分享入口、内容去重或多服务器。

## 2. 上传

- 可多选及追加，在进程内排队并逐个上传；最多一个活动上传，包含暂存和未知结果协调。等待项不申请服务器额度，也不提前复制。
- 使用 ContentResolver 流式读取所选 URI，不假定真实文件路径，不申请全盘管理权限。
- 需要获取实际大小或稳定当前传输载荷时，对当前文件生成私有临时快照。只有一个快照；按服务端单文件限制和本机可用空间限制读取，超限或磁盘不足明确失败。不得将完整文件读入内存。
- 快照完成后固定元数据和发送身份，复用 Spec 002 的单轮协议；失败后重新选择属于新发送，不保留快照供同次重传。
- 明确失败后可继续等待项，重发须重新选择；结果未知暂停队列，由用户手动查询或结束本轮，不自动查询或保留一组失败快照。不建设独立原子暂存额度账本。
- 等待项可移除；结束本轮时中断本机读写、清理快照和全部队列上下文，不再协调旧任务。未知服务器结果不能当作已取消；提示先检查历史，再选择是可能重复的新发送，由服务器额度与资源限制兜底。
- 上传成功、明确失败、结束本轮或进程重启后清理临时数据；清理失败提示并暂停新的暂存，用户处理后重试。不恢复持久队列。
- 显示进度和本地“中断传输”入口；100% 后等待服务端确认，中断不调用服务端 stop，也不证明文件不会保存。服务端容量、安全清理和认证语义保持 Spec 002 不变。

## 3. 下载与系统保存

- 最多一个活动下载，不建立下载等待队列；完成后可以再次主动下载。
- 用户通过系统创建文档流程选择保存位置。先以认证请求下载到私有临时文件，核对成功响应及字节数，再复制到选定 URI；全部写入并关闭成功后才报告保存成功。
- 错误响应、重定向或认证失败不能作为文件保存，不把带 Token 的远程 URL 交给外部应用。
- 任一步骤失败或中断都如实提示，清理私有临时文件；系统目标可能留下不完整文件，尽力移除，并提示用户在文件管理器检查。不承诺跨文档提供方的原子保存、自动恢复或撤回覆盖。
- 保存位置、同名和覆盖由系统选择流程及提供方处理，不维护应用内重名分配表；用户应选择新文件，避免覆盖重要内容。
- 完成副本由系统管理，不依赖 FileHop 登录或服务器在线才能打开。服务器删除不影响它；卸载/清除 FileHop 数据不主动删除系统保存的文件，实际保留与备份由目标提供方决定。
- 不保留副本索引、长期 URI 授权或应用内打开管理入口。再次下载是新操作；失败从头重下。

## 4. 生命周期与服务器管理

只保证前台传输；后台暂停新任务，不主动取消已开始传输，不引入前台服务或 WorkManager。旋转不重复启动，进程终止后不自动重发；恢复时清理私有临时数据即可，不重建任务数据库。

认证失效中断本机上传、清空等待项和文件引用/快照，提示需重新选择；只保留草稿及未确认发送身份供重登后手动处理，不自动恢复队列。主动退出清空敏感上下文并中断本机传输，不请求服务端停止。凭证保护和旧响应隔离沿用 Spec 005，不承诺退出能撤回服务器已提交消息或系统已保存文件。

首版从文件消息下载即可；独立 Android 服务器文件管理页不作为手机文件闭环前置，清理服务器空间可先使用已实现的 Web 页。以后有实际需求再复用 Spec 003，不另造删除协议。

## 5. 最小验证

- F01：实际手机通过系统选择器与 Web 双向交换文件，多选串行发送可用。
- F02：文件过大、空间不足、源 URI 读取失败时明确报错，内存与暂存有界。
- F03：上传响应丢失不自动重传，手动查询原身份；中断不报撤回，结束本轮提示重复风险；失败后重新选择为新发送。
- F04：下载错误不报成功，保存失败提示可能的残留；正常系统保存可由文件管理器打开，服务器删除不影响副本。
- F05：旋转不重复传输，进程终止不自动重发；私有临时数据可清理，不误删用户文件。

旧 F01–F15 中的本地索引、并发调度和持久恢复要求已撤销。只验证实际使用的系统选择/保存提供方，不建设全平台矩阵；不把系统文件管理功能重新实现一遍。
